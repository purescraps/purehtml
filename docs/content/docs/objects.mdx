## Basic Object Extraction

Extracting an object is defined with `type: object` and a `properties:` map of field names to sub-configurations:

<PureHtmlSnippet
  inputHtml={`<div>
  <span class="firstname">John</span>
  <span class="lastname">Doe</span>
  <span class="age">42</span>
</div>`}
  configYaml={`type: object
properties:
  firstName: { selector: .firstname }
  lastName: { selector: .lastname }
  age: { selector: .age }`}
/>

## Property Transformers on Parent Elements

If a property does not specify a `selector`, any defined transformers execute directly in the scope of the parent element. For instance, extracting an attribute from the parent container:

<PureHtmlSnippet
  inputHtml={`<div id="course-details" data-course-id="9999">
  <h1>Web Scraping Fundamentals</h1>
</div>`}
  configYaml={`selector: '#course-details'
type: object
properties:
  courseId: { transform: [attr(data-course-id), number] }
  title: { selector: h1, transform: [trim] }`}
/>

<Callout type="info">
  You can omit `type: object` if the `properties` mapping is present in the configuration.
</Callout>
